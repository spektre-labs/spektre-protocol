# CHANGES_SUMMARY

## Overview

This repository was reorganized into a layered conceptual structure.

The reorganization had two goals:

- make the canonical center visible
- preserve the wider idea-space without flattening it into the core

## Major Structural Result

The repository now uses these top-level layers:

- `protocol_core/`
- `formal_structure/`
- `execution_system/`
- `human_layer/`
- `ai_interface/`
- `applied_protocols/`
- `essays/`
- `explorations/`
- `archive/`
- `docs/`

## Main Reorganization Pass

The main pass:

- moved former root materials into layer-based folders
- separated canonical, formal, execution, human, AI-interface, applied, exploratory, and archive material
- preserved the previous protocol-centered root `README.md` as `protocol_core/reference/README_SPEKTRE_V1_1.md`
- added a new repository-level `README.md`
- built navigation documents under `docs/`
- subdivided `archive/` internally

## Earlier Polish Passes

Earlier refinement passes reduced gray areas by moving several documents from `explorations/` into more exact layers such as `docs/reference/`, `human_layer/meaning/`, `protocol_core/boundaries/`, and `archive/legacy_root/`.

Examples:

- `CODEX.md` -> `docs/reference/CODEX.md`
- `BABEL.md` -> `docs/reference/BABEL.md`
- `SUBJECT–OBJECT_COLLAPSE.md` -> `human_layer/meaning/SUBJECT–OBJECT_COLLAPSE.md`
- `CONSCIOUSNESS.md` -> `human_layer/meaning/CONSCIOUSNESS.md`
- `RE_COGNITION.md` -> `human_layer/meaning/RE_COGNITION.md`
- `FREEDOM.md` -> `protocol_core/boundaries/FREEDOM.md`
- `IDENTITY.md` and `IDENTITY_ALIASING.md` -> `archive/legacy_root/`

## Final Refinement Pass

A final classification pass added more precision where it materially improved navigation.

### New precise placements

- `GNOSIS.md` -> `human_layer/meaning/GNOSIS.md`
- `INFINITE_PROCESS.md` -> `execution_system/runtime/INFINITE_PROCESS.md`
- `THEORY_OF_TRUTH.md` -> `formal_structure/reference/THEORY_OF_TRUTH.md`
- `EVERYTHING_IS_FREE.md` -> `essays/economy_access/EVERYTHING_IS_FREE.md`

### New essay classifications

The `essays/` layer was split into domain shelves:

- `essays/health_biology/`
- `essays/learning_work/`
- `essays/economy_access/`
- `essays/culture_society/`
- `essays/infrastructure_environment/`

This converted `essays/` from a flat applied shelf into a navigable applied-domain layer.

## Mechanical Text Updates Already Performed

Earlier in the process, the repository also received mechanical terminology normalization.

- name normalization to `Lauri Elias Rainio`

These were textual substitutions only, not rewrites of argument structure.

## Preservation Decisions

- No content was intentionally deleted.
- The canonical protocol material was not rewritten into a different theory.
- Older, parallel, difficult, or speculative documents were preserved in `archive/` or `explorations/`.
- Unusual filenames such as `ARCHITECTURE.md.` were preserved.
- The old root README was preserved instead of being overwritten and lost.

The repository now reads as:

- AI/substrate boundary
- applied protocols

- exploratory concept space

That is the intended final shape of the repository as a readable conceptual ecosystem.
